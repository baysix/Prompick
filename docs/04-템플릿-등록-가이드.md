# 템플릿 등록 가이드

운영자가 템플릿 하나를 처음부터 공개까지 올리는 절차. 실제로 미니미·잠금화면 두 개를 올리면서
걸렸던 것들을 그대로 적었다.

---

## 0. 시작 전에 준비할 것

| 준비물 | 없으면 | 어디서 |
|---|---|---|
| 프롬프트 원문 | 만들 수 없다 | 직접 작성 |
| 예시로 쓸 결과물 | 아무도 안 고른다 | 프롬프트를 직접 돌려서 뽑는다 |
| 제공사 API 키 | 제작이 전부 실패한다 | 관리자 → 제공사 키 |

**예시 결과물을 먼저 뽑아라.** 프롬프트가 의도대로 나오는지 확인도 되고, 그게 곧 목록에 걸릴
그림이 된다. 순서를 바꾸면 "공개해뒀는데 예시가 없는 템플릿"이 남는다.

> 예시 이미지는 **공개 버킷**에 올라간다. 로그인 없이 누구나 볼 수 있고 검색에도 노출된다.
> 사람 얼굴이 들어간 사진을 쓸 때는 그 점을 먼저 확인하라.

---

## 1. 기본 정보

관리자 → 템플릿 → **새 템플릿**

### 반드시 맞춰야 하는 것

**주소(slug)** — `/t/여기`가 된다. 영문 소문자·숫자·하이픈만.
**공개한 뒤에는 바꾸지 마라.** 공유된 링크와 검색 색인이 전부 끊긴다.

**비율과 해상도는 서로 맞아야 한다.** 이게 어긋나면 사용자에게 "비율 1:1"이라고 보여주면서
실제로는 2:3짜리를 주게 된다. 탐색 필터도 틀린 값으로 걸린다.

| 해상도 | 비율 |
|---|---|
| 864×1536 | 9:16 |
| 1024×1536 | 2:3 |
| 1024×1024 | 1:1 |
| 1536×1024 | 3:2 |

**gpt-image-2.5를 쓴다면 가로·세로가 모두 16의 배수여야 한다.**
흔히 쓰는 `1080×1920`은 1080이 16으로 나눠떨어지지 않아 거절당한다. 9:16이 필요하면
`864×1536`을 쓴다.

### 요금은 두 개다

이 서비스는 한 템플릿을 두 가지로 판다. 둘은 **독립적**이라 하나만 열어도 된다.

- **프롬프트 원문** — `공개하지 않음` / `누구나 무료로` / `프롬비를 받고`
- **대신 만들어 주기** — `프롬비를 받고` / `무료로 (하루 횟수 제한)`

대부분의 템플릿은 **프롬프트는 비공개, 제작은 유료**가 기본이다. 프롬프트를 공개하면
우리를 거치지 않고 쓸 수 있으니, 공개할 때는 그럴 이유가 있어야 한다(유입용 미끼 등).

무료로 열면 **매출 0원인데 원가는 그대로 나간다.** 건당 300원 안팎이다. 무료 템플릿을 늘릴
때는 매출·원가 화면을 같이 보라.

### 사진 안내

`한 줄 요약`은 목록과 상세에 먼저 뜬다. `확인할 것`은 업로드 화면에 체크리스트로 나온다.

여기를 대충 쓰면 실패율이 오르고 문의가 늘어난다. 실제로 "얼굴이 가려지지 않은 사진" 한 줄을
넣고 안 넣고가 결과 차이를 만든다.

## 2. 사진 입력 필드

기본 정보를 저장하면 템플릿 id가 생긴다. 그때부터 나머지 탭이 열린다.

입력 필드의 **필드 키**는 파이프라인이 사진을 찾을 때 쓰는 이름이다. 예: `child_photo`,
`person_photo`. 이 이름이 파이프라인의 `inputs` 값과 **정확히 같아야** 한다. 다르면 사진이
전달되지 않고, 사진 없이 글만으로 만들어져 엉뚱한 결과가 나온다.

최소 크기는 **200×200**을 권한다. 그보다 높게 잡으면 폰으로 찍어 메신저로 한 번 오간 사진이
막힌다. 실제로 400으로 잡았다가 정상적인 사진이 거절당했다.

---

## 3. 프롬프트 — 두 종류를 혼동하지 말 것

**완전히 다른 두 개이고, 테이블도 따로다.**

| | 공개 프롬프트 | 파이프라인 지시문 |
|---|---|---|
| 누가 보나 | 사용자 | 아무도 (서버만) |
| 무엇인가 | 복사해서 자기 AI에 붙여넣는 글 | 우리가 모델에 보내는 내부 지시 |
| 어디에 쓰나 | 프롬프트 열람 상품 | 자동 제작 |
| 새면 | 괜찮다 (그게 상품) | **우리가 파는 것을 잃는다** |

같은 내용이어도 두 군데에 각각 적는다. 한쪽을 공개로 바꾸다 다른 쪽이 딸려 나가는 일을
구조적으로 막기 위해서다.

---

## 4. 파이프라인

### 경로 고르기 — `api` 파라미터

| 값 | 언제 | 어떻게 동작하나 |
|---|---|---|
| `responses` | **지시문에 해석이 필요할 때** | 추론 모델이 사진을 보고 글을 읽은 뒤 이미지 툴을 부른다 |
| `images` | 프롬프트가 곧 그림 묘사일 때 | 이미지 모델에 바로 넣는다. 조금 싸고 빠르다 |

**"누끼를 따서", "3~7개를 모두 다르게", "상단 40%를 비워 시계 자리를 남길 것"** 같은 문장은
판단을 요구한다. 그림 모델은 글을 읽고 판단하지 않으므로 `images`로 넣으면 단어 뭉치로
취급된다. 실제로 같은 프롬프트를 두 경로로 돌렸더니, `images`는 "3D 토이 스타일"을 무시하고
실사 축소판을 내놓았다.

한국어로 길게 쓴 지시문이면 거의 항상 `responses`다.

### 파라미터

```
api            responses
mainlineModel  gpt-5.4          앞에 세울 추론 모델
size           864x1536         16의 배수
quality        high
```

**`mainlineModel`을 최상위 모델로 잡지 마라.** 이 자리가 하는 일은 사진 보고 글 읽고 툴 부르는
것이 전부다. 실측해보니 출력이 **490 토큰**밖에 되지 않았다. 출력 단가가 비싼 모델을 쓰면
쓰지도 않는 능력에 돈을 낸다.

| 모델 | 추론 단계 원가 |
|---|---|
| gpt-6-astra | 81원 |
| **gpt-5.4** (기본) | **22원** |
| gpt-5.4-mini | 7원 |

`input_fidelity`는 **넣지 마라.** gpt-image-2.5는 입력 이미지를 항상 고충실도로 다루므로
이 값을 보내면 오류로 거절한다.

### 입력 연결

```
image = person_photo
```

왼쪽은 제공사에 넘길 파일 이름, 오른쪽은 **2번에서 만든 입력 필드 키**다.

## 5. 예시 결과물

올릴 때 서버가 **실제 픽셀 크기를 재서 저장한다.** 목록의 타일이 그 비율 그대로 자리를 잡으므로,
정사각이든 가로로 길든 잘리지 않는다. 비율을 맞추려고 일부러 자를 필요가 없다.

첫 번째 것이 목록의 대표가 된다.

영상이나 SVG처럼 크기를 읽을 수 없는 형식은 비워두고, 화면이 템플릿 출력 비율로 대신한다.

---

## 6. 공개

목록에서 **공개** 버튼을 누른다. 아래 셋 중 빠진 게 있으면 버튼이 눌리지 않는다.

- 공개 프롬프트 (프롬프트를 공개로 설정한 경우만)
- 실행 파이프라인
- 예시 결과물

공개해놓고 아무 일도 일어나지 않는 템플릿이 가장 나쁘다. 사용자는 돈을 내려다 막히고,
운영자는 무엇이 빠졌는지 모른다. 대시보드의 **"공개했는데 비어 있어요"** 칸이 이걸 잡아준다.

---

## 7. 안 되면 어디를 보나

| 증상 | 먼저 볼 곳 |
|---|---|
| 제작이 전부 실패 | 관리자 → 제공사 키 → **연결 확인**. 키·모델 이름을 한 번에 확인한다 |
| `rate_limit_exceeded, Limit 0` | 그 모델이 계정에 안 열렸다. 결제수단 등록 후 **15~30분** 기다린다 |
| `no credits remaining` | OpenAI 잔액 0. ChatGPT 구독과 **별개** 지갑이다 |
| 사진이 안 올라감 | 최소 크기. 에러 메시지에 실제 크기가 찍힌다 |
| 결과가 지시와 다름 | `api`가 `images`로 되어 있는지 확인 |
| 어느 단계에서 깨졌나 | 관리자 → 제작 내역에서 작업을 찾는다 |

---

## 8. 등록 후 챙길 것

**원가를 실제 값으로 맞춰라.** 관리자 → AI 모델에서 1회 원가를 넣는다. 이 값이 틀리면
매출·원가 화면이 실제보다 남는 것처럼 보인다.

한 단계에 추론 모델과 이미지 모델이 함께 드는 경우, **두 값의 합**을 그 모델 행에 넣는다.
원가 계산은 단계별 모델 원가를 더하는 구조라, 따로 두면 추론 요금이 어디에도 잡히지 않는다.

현재 기준값: `gpt-image-2.5-sunburst` = **302원** (추론 22원 + 이미지 280원)
