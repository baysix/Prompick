# 디자인 방향

벤치마킹: [canva.com/ko_kr](https://www.canva.com/ko_kr) — 색, 구조, 카피 톤 전부.
(vrew.ai는 초기 참고였고, 캔바로 바꿨다. 캔바는 자동 접근을 막아 두어 직접 읽지 못했고
알려진 디자인 언어를 바탕으로 옮겼다.)

## 캔바에서 가져온 것

실제 캔바를 브라우저로 열어 확인한 값이다. (WebFetch는 403이라 Playwright로 읽었다)

- **히어로는 그라데이션이 영역 전체를 덮고 글자는 흰색.** 버튼은 흰 알약 하나뿐이다.
  처음 온 사람에게 필요한 건 선택이 아니라 시작이라, 버튼을 둘로 나누지 않는다.
  (처음에 "검색창 중심"이라고 적었던 것은 틀렸다. 랜딩에 검색창은 없고 로그인 후 대시보드에만 있다)
- **가운데 큰 제목 → 알약 탭 → 세로 카드 가로 스크롤 → 가운데 더보기 버튼.**
  이 묶음이 섹션마다 반복된다.
- **카드는 오른쪽에서 잘린다.** 더 있다는 걸 화살표나 안내 문구 없이 알린다.
- **모서리 12px이 압도적**(197곳), 버튼 20px, 탭은 알약형.
- **보라 #8B3DFF** (실측값)
- **보라 → 청록 그라데이션.** 단색 파랑보다 "만드는 재미"에 가깝고, AI 서비스가 흔히 쓰는
  남색·형광 조합과 겹치지 않는다. 주요 버튼과 마지막 CTA에만 쓴다.
- **큼직한 둥근 모서리와 넉넉한 여백.**
- **큰 제목.** 히어로 52px, 섹션 제목 19~28px, 본문 15~17px.

## vrew에서 가져올 것

### 1. 랜딩은 카탈로그가 아니라 "설득하는 페이지"

지금 우리 홈은 결과물 격자를 깔고 바로 목록으로 넘어간다. vrew는 다르다.
**무엇을 해주는 서비스인지 섹션마다 하나씩** 설명하고, 마지막에 다시 권한다.

vrew 섹션 순서:

```
히어로 (한 줄 약속 + 큰 스크린샷 + CTA 2개)
  ↓
핵심 기능 3개 (각각 텍스트 + 이미지, 번갈아 배치)
  ↓
사용자 후기 (인용문 + 사진 + 직업)
  ↓
같이 주는 것 (아이콘 4개 + 라벨)
  ↓
기능 카드 6개 (아이콘 + 제목 + 설명)
  ↓
활용 사례 4개 (이미지 + 제목 + 설명)
  ↓
믿을 수 있는 이유 (인증 배지)
  ↓
마지막 CTA
```

우리 버전으로 옮기면:

```
히어로       결과물 격자 + "릴스에서 본 그 영상, 사진 한 장이면 돼요" + CTA 2개
어떻게 쓰나   ① 프롬프트 받아 가기  ② 대신 만들어 드리기   (둘 다 보여줘야 한다)
이번 주 인기   결과물 가로 스크롤
만드는 법     사진 올리기 → 기다리기 → 받기, 세 컷
갤러리        남이 만든 것
이런 분들이    소상공인 / 릴스 운영자 / 그냥 재미로
믿어도 되는 이유  실패하면 환불, 30일 보관, 프롬비 유효기간 없음
마지막 CTA
```

### 2. 여백을 크게

섹션 사이 60~80px. 지금 우리 화면은 촘촘해서 정보가 밀린 느낌이다.

### 3. 글자 크기 대비

제목:본문 = 약 2:1. 제목 32px 이상, 본문 16~18px, 보조 14px.
지금 우리는 제목이 작고 본문이 13px이라 전반적으로 작다. 한 단계씩 키운다.

### 4. 둥근 모서리

버튼 8~12px(또는 완전한 알약형), 카드는 살짝. 지금 값과 크게 다르지 않다.

### 5. 카피 톤

짧고 친근한 존댓말. "도와줄게요", "~할 수 있어요".
지금 우리 문구가 이미 이 톤이므로 유지한다.

### 6. 아이콘

기능마다 SVG 아이콘 하나. 장식이 아니라 구분용이다.

## 우리에게 맞게 바꿀 것

vrew는 **설치해서 쓰는 편집 프로그램**이고 우리는 **결과물을 보고 고르는 플랫폼**이다.
그래서 이 둘은 다르게 간다.

| | vrew | 프롬픽 |
|---|---|---|
| 히어로 | 제품 스크린샷 한 장 | 결과물 격자 (여러 개가 동시에 움직임) |
| 증거 | 후기 인용문 | 결과물 그 자체 |
| 전환 목표 | 다운로드 | 무료로 한 번 만들어 보기 |

결과물이 주인공이라는 원칙은 유지한다. 색을 갖는 것은 주요 버튼(파랑)·무료(초록)·유료(금색)뿐이고
나머지는 흰색과 회색으로만 만든다.

```
ground        #ffffff

line          #e5e7ec
ink           #16181d   ink-soft #5a616e   ink-faint #9aa1ae
accent        #2b62ff   accent-soft #eaefff
free          #15803d   paid #9a6a12
```

vrew 기준으로 맞춰둔 값이라 그대로 쓴다. 바꿀 것은 **여백·글자 크기·섹션 구성**이다.
